# 투자 일지 기능 상세 명세서

**목적**: 사용자가 자신의 투자 활동을 체계적으로 기록·관리·분석할 수 있는 종합 투자 일지 기능을 제공합니다.  
**핵심 철학**: 종목 중심 + 태그 기반 + 마크다운 자유 작성 + DB 완전 연동

---

## 1. 기능 개요

- **투자 일지 작성 기능**: 사용자가 매일/매 거래마다 자유롭게 투자 생각, 분석, 감정, 계획 등을 기록
- **종목 기반 작성**: 모든 일지는 반드시 하나 이상의 **종목**과 연결 (주식, ETF, 코인, 채권, 펀드 등 지원)
- **태그로 분류**: 자유 태그 + 시스템 추천 태그로 강력한 검색·필터링 가능
- **마크다운으로 작성**: GitHub Flavored Markdown(GFM) 완전 지원 + 실시간 미리보기
- **데이터베이스 연동**: 작성된 모든 일지는 DB에 영구 저장되며, 언제든지 조회·검색·수정·삭제·내보내기 가능

---

## 2. 상세 기능

### 2.1 일지 작성 화면

#### 필수 입력 항목
| 항목              | 설명                                      | 필수 여부 | 비고 |
|-------------------|-------------------------------------------|-----------|------|
| 종목              | 종목코드/이름 검색 후 선택                | 필수      | 다중 종목 선택 가능 |
| 작성일시          | 자동 기록 (수동 수정 가능)                | 필수      | 타임스탬프 |
| 제목              | 일지 제목 (최대 100자)                    | 필수      | - |
| 본문              | 마크다운 에디터                           | 필수      | GFM 지원 |
| 태그              | #태그 형식 또는 태그 입력기               | 선택      | 최대 15개 |
| 투자 유형         | 매수 / 매도 / 보유 / 분석 / 계획 / 반성 | 선택      | 다중 선택 가능 |
| 거래 정보         | 수량, 단가, 총액, 수수료                  | 선택      | 자동 수익률 계산 가능 |

#### 선택 입력 항목 (보완 기능)
- **감정 지수**: 1~5점 스케일 또는 emoji (😀 😐 😞)
- **투자 기간**: 단기 / 중기 / 장기
- **목표 수익률** 및 **실제 수익률** (자동 계산 옵션)
- **첨부 파일**: 차트 이미지, 뉴스 스크린샷, PDF 리포트 등 (최대 10MB)
- **관련 뉴스/링크**: URL 자동 파싱 및 미리보기
- **AI 보조 작성**: "이 종목에 대한 내 생각을 마크다운으로 정리해줘" 버튼 (Grok 연동 예정)

### 2.2 마크다운 에디터 기능
- 실시간 미리보기 (Split view)
- 이미지 드래그 앤 드롭 업로드
- 테이블, 체크리스트, 코드 블록, 인용구, 수식(KaTeX) 지원
- 템플릿 기능 (예: “매수 일지”, “분석 일지”, “반성 일지”)

### 2.3 태그 시스템
- **자유 태그**: 사용자가 직접 입력 (#매수, #기술적분석, #리스크관리 등)
- **시스템 추천 태그**: AI가 본문 분석 후 자동 제안
- **프리셋 태그 카테고리**:
  - 전략: #가치투자, #모멘텀, #배당, #단타
  - 감정: #공포, #탐욕, #확신, #후회
  - 시장: #상승장, #하락장, #횡보, #FOMC
  - 섹터: #반도체, #2차전지, #AI, #바이오

### 2.4 데이터베이스 설계 (개요)

```sql
-- 주요 테이블 예시
CREATE TABLE investment_journals (
    id            SERIAL PRIMARY KEY,
    user_id       UUID NOT NULL,
    stock_code    VARCHAR(20),
    stock_name    VARCHAR(100),
    title         TEXT,
    content       TEXT,           -- 마크다운 원본
    html_content  TEXT,           -- 렌더링된 HTML (선택)
    created_at    TIMESTAMPTZ,
    updated_at    TIMESTAMPTZ,
    tags          TEXT[],         -- 배열 타입
    trade_type    TEXT[],         -- 매수/매도 등
    amount        NUMERIC,
    price         NUMERIC,
    total         NUMERIC,
    sentiment     SMALLINT,       -- 1~5
    attachments   JSONB
);
