# 스코어링 설계 (Scoring Design)

미국 주식 · 다수 종목 스크리닝 · FMP 무료 티어 기준.

---

## 0. 기본 원칙

- **각 기준 → 0~5점 서브스코어**로 정규화.
- **4개 영역별 가중합 → 종합 점수(0~100)**.
- 두 가지 사용 방식을 분리:
  - **하드 필터(screening)**: 조건 미달 종목을 후보에서 제외 (통과/탈락).
  - **랭킹 팩터(ranking)**: 통과 종목을 종합 점수로 정렬.
- **프리셋**(가치형 / 성장형 / 균형형)으로 가중치를 통째로 바꿈.
- 데이터 없는 정성 기준은 **중립(3점)** 기본값 + 수동 오버레이로 덮어씀.

### 정규화 규칙 (밴드 방식)
각 기준은 `[임계값→점수]` 밴드 테이블로 매핑. 예: PER ≤ 10 → 5점.
섹터 편차가 큰 지표(PER, PBR, 영업이익률 등)는 **2단계 구현**:
- v1: 아래의 절대 밴드
- v2: **섹터 내 백분위**로 교체 (동종업계 상대평가) — 정확도↑

---

## 1. 영역 1 — 기본적 분석 (가치·재무) · 7개

| # | 기준 | 필드(FMP) | 5 | 4 | 3 | 2 | 1 | 0 |
|---|------|-----------|---|---|---|---|---|---|
| 1 | PER | `peRatioTTM` | ≤10 | ≤15 | ≤20 | ≤30 | ≤50 | >50 or <0 |
| 2 | PBR | `priceToBookRatioTTM` | ≤1 | ≤1.5 | ≤3 | ≤5 | ≤8 | >8 |
| 3 | ROE | `returnOnEquityTTM` | ≥20% | ≥15% | ≥10% | ≥5% | ≥0% | <0% |
| 4 | EV/EBITDA | `enterpriseValueOverEBITDATTM` | ≤6 | ≤8 | ≤11 | ≤15 | ≤20 | >20 or <0 |
| 5 | 배당수익률 | `dividendYieldTTM` | ≥3% | ≥2% | ≥1% | ≥0.5% | >0% | 0% |
| 6 | 부채비율(D/E) | `debtToEquityTTM` | ≤0.5 | ≤1.0 | ≤1.5 | ≤2.0 | ≤3.0 | >3.0 |
| 7 | 유보율 | `1 - payoutRatioTTM` | — | — | — | — | — | — |

- **#5 배당**: 성장형 프리셋에서는 가중치 ≈ 0 (무배당이 결함이 아님).
- **#6 부채비율**: 금융·유틸리티는 구조적으로 높음 → v2 섹터 상대평가 필요. FMP `debtToEquity`는 배수(0.5 = 50%).
- **#7 유보율**: 한국식 유보율(잉여금/자본금)과 다름. `1-payout`을 **재투자 성향 프록시**로 사용, 가중치 낮게. 성장형은 높을수록 +, 가치·배당형은 중립.

## 2. 영역 2 — 성장성·비즈니스 모델 · 5개

| # | 기준 | 소스 | 5 | 4 | 3 | 2 | 1 | 0 |
|---|------|------|---|---|---|---|---|---|
| 8 | 매출/영업이익 성장률 | `revenueGrowth`,`epsgrowth` 평균 | ≥20% | ≥15% | ≥10% | ≥5% | ≥0% | <0% |
| 9 | 영업이익률 | `operatingProfitMarginTTM` | ≥25% | ≥20% | ≥15% | ≥10% | ≥5% | <5% |
| 10 | 경제적 해자 🟠 | 프록시: 5yr ROIC + 마진 안정성 | 아래 프록시식 | | | | | |
| 11 | TAM 🟠 | 섹터 성장률 프록시 | 기본 3(중립) | | | | | |
| 12 | 경영진·거버넌스 🟡 | 자사주 감소 + 내부자 지분 | 기본 3(중립) | | | | | |

- **#10 해자 프록시**: `moat = 0.5*ROIC점수 + 0.3*총마진점수 + 0.2*마진안정성`. 5년 평균 ROIC ≥15% & 총마진 유지 → 고득점. 데이터 부족 시 ROE+총마진 축약.
- **#11 TAM**: 자동화 곤란. 섹터 성장률 밴드 or 수동. 기본 중립(3), 가중치 낮음.
- **#12 거버넌스**: 발행주식수 감소(자사주 소각)면 +, 희석되면 −. 내부자 지분 데이터는 무료 티어 제한 → 부분 자동.

## 3. 영역 3 — 기술적 분석·수급 · 4개 (가격 히스토리 계산)

| # | 기준 | 계산 | 점수 로직 |
|---|------|------|-----------|
| 13 | 이동평균선 | 20/60/120일 MA | 정배열(P>20>60>120)=5, 위 MA 개수·정렬로 감점 |
| 14 | 거래량 | 20일 평균 대비 | 상승일 거래량 실림=가점, 하락일 거래량 실림=감점 |
| 15 | 기관 수급 🟡 | `institutionalOwnership` 분기 변화 | 증가=+, 감소=−. **후행지표(13F)**, 가중치 낮음 |
| 16 | RSI/MACD | 14일 RSI, MACD(12,26,9) | RSI 40~60 건전 + MACD>Signal 골든크로스=가점 |

- **#15**: 미국은 "외국인 수급" 개념 없음 → 기관 지분만. 분기 지연 반영해 가중치 최소.
- 영역 3은 **품질이 아니라 타이밍** 신호 → 스크리닝 하드필터보다 랭킹 보조에 적합.

## 4. 영역 4 — 매크로·리스크 관리 · 4개

| # | 기준 | 처리 | 점수 로직 |
|---|------|------|-----------|
| 17 | 금리·환율 🟠 | 전 종목 공통 컨텍스트 | 시장 레짐 표시 + 섹터 금리민감도 플래그(개별 차별화 아님) |
| 18 | 지정학·규제 🔴 | 수동 오버레이 태그 | 기본 중립(3), 사용자가 리스크 태그 부여 시 감점 |
| 19 | 밸류에이션 밴드 | 자기 PER/PBR 5년 백분위 | ≤20%ile(저평가)=5 … ≥80%ile(고평가)=0 |
| 20 | 손익비 🟡 | (목표가−현재가)/(현재가−손절) | 손절=P−2·ATR, 목표=애널리스트 평균. ≥3=5, ≥2=4, ≥1.5=3, ≥1=2, <1=0 |

- **#17**: 개별 종목 점수라기보다 **전체 시장 판단 배너 + 섹터 태그**로 UI에 표시.
- **#19**: FMP 무료로 과거 비율 확보 제한 시 → yfinance 가격 히스토리 + EPS로 자체 계산.
- **#20**: 애널리스트 목표가 없으면 최근 고점/저항선으로 대체.

## 5. 종합 점수 & 프리셋

```
composite = Σ (영역가중치 × 영역내_가중평균_서브스코어) × 20   # 0~100 스케일
```

### 영역 가중치 프리셋

| 영역 | 균형형 | 가치형 | 성장형 |
|------|:---:|:---:|:---:|
| 1 기본(가치·재무) | 30% | 45% | 15% |
| 2 성장성 | 25% | 15% | 45% |
| 3 기술·수급 | 20% | 15% | 25% |
| 4 매크로·리스크 | 25% | 25% | 15% |

- **가치형**: PER/PBR/배당/밸류밴드↑, 성장/모멘텀↓
- **성장형**: 성장률/영업이익률/해자/모멘텀↑, 배당/PBR≈0
- 영역 내 개별 가중치도 프리셋별로 지정 (config로 분리).

## 6. 하드 필터 (스크리닝 기본 세트, 토글 가능)

- 흑자 필터: `ROE > 0` & `영업이익률 > 0`
- 재무 안정: `부채비율(D/E) < 3`
- 추세 필터: `현재가 > MA120` (하락추세 종목 제외)
- 밸류 필터: `밸류에이션 밴드 백분위 < 80` (역사적 고평가 제외)
- (선택) 배당 필터: `배당수익률 > 0` — 배당 전략일 때만

## 7. 데이터 가용성 요약 (FMP 무료 티어)

| 상태 | 개수 | 기준 |
|------|:--:|------|
| ✅ 완전 자동 | 14 | 1,2,3,4,5,6,8,9,13,14,16,19,7,20* |
| 🟡 부분/프록시 | 4 | 10,12,15,20 |
| 🟠 컨텍스트/정성 | 3 | 11,17,18 |

- 무료 티어 제약: **250 콜/일**, 미국 종목, 과거 데이터 제한 → **캐싱 + S&P500 범위**로 시작.
- 과거 비율·가격 히스토리는 **yfinance 폴백**으로 보강 (#19, #13, #14, #16).

## 8. 미해결/확인 필요 (검토 요청)

1. 절대 밴드 vs 섹터 상대평가 — v1은 절대 밴드로 시작하기
2. 프리셋 3종(균형/가치/성장) 이대로 추가
3. 하드 필터 기본 세트 동의함
4. 배당(#5)·유보율(#7) 가중치 처리 방향? -> 적절히 조정 가능.
5. 정성 3종(해자·TAM·거버넌스)을 프록시 자동으로 갈지, 수동 입력 UI로 갈지? -> 기본적으로 수동
