# Legal Spec

이용약관(`/terms`), 개인정보처리방침(`/privacy`) 페이지 사양.

## 1. 정책

- 두 페이지 모두 **공개**(비로그인 접근 가능).
- 회원가입(=Google 첫 로그인) 전 `/login`에서 두 페이지 링크 노출.
- 헤더 사용자 메뉴와 푸터에서 상시 접근 가능.

## 2. 구현 방식

- 동적 데이터 없음 → 서버 컴포넌트로 정적 렌더.
- 텍스트는 TSX 인라인 (한국어). 추후 다국어/CMS 이전 가능.
- 텍스트 분량이 한 파일 500줄을 넘으면 섹션 단위로 분할 (`features/legal/ui/sections/*`).

## 3. 모바일 최적화

| 항목 | 적용 |
|------|------|
| 컨테이너 | `max-w-screen-md mx-auto px-4 sm:px-6 py-8 sm:py-12` |
| 본문 폰트 | 모바일 `text-[15px] leading-relaxed`, sm 이상 `text-base` |
| 헤더 / 섹션 | `text-2xl sm:text-3xl` (h1), `text-lg sm:text-xl` (h2) |
| 목차 (TOC) | 모바일에선 스크롤 가능한 칩 형태, sm 이상에선 사이드 sticky 리스트 |
| 길이 제한 | 한 줄 너비 65~75ch 유지 (`prose prose-neutral max-w-prose`) |
| 다크 모드 | `prose-invert` 자동 적용 |
| 안전영역 | `pb-[env(safe-area-inset-bottom)]` 푸터 |

## 4. 페이지 구성

### `/terms` (이용약관)
1. 제1조 목적
2. 제2조 정의
3. 제3조 약관의 효력 및 변경
4. 제4조 이용계약의 성립
5. 제5조 회원의 의무
6. 제6조 서비스의 제공 및 변경
7. 제7조 서비스 이용 제한
8. 제8조 책임 제한
9. 제9조 분쟁의 해결
10. 부칙 (시행일)

### `/privacy` (개인정보처리방침)
1. 수집하는 개인정보 항목 (Google 계정의 이름, 이메일, 프로필 이미지)
2. 수집 방법 (Google OAuth 콜백)
3. 수집 및 이용 목적 (가입·식별, 서비스 제공)
4. 보유 및 이용 기간 (회원탈퇴 즉시 파기)
5. 제3자 제공 / 위탁 (없음. Neon은 처리 인프라로 명시)
6. 이용자의 권리 (열람·정정·삭제·탈퇴 절차)
7. 안전성 확보 조치 (HTTPS, OAuth, 최소 권한)
8. 개인정보 보호책임자 (이메일 placeholder)
9. 변경 고지 절차

## 5. 검증

- 빌드 통과
- 320px 폭에서 가로 스크롤이 발생하지 않을 것
- 다크 모드에서 `prose-invert` 적용 확인 (수동)
- a11y: 각 섹션은 `<section aria-labelledby>` + `<h2 id>` 형태
